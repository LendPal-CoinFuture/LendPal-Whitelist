# LendPal 白名单

AccessRegistry 是 LendPal 的准入合约。它用 UUPS 代理部署在 Sepolia，地址不变：

`0x135Fb34eBAd72BB91932E22ff48Fa6963f0e5F9E`

身份只有三种：超级管理员、普通管理员、普通地址。超级管理员和普通管理员在产品里都算已经准入，和白名单用户一样。

## 功能

### 超级管理员

- 合约的 owner。不能把所有权交到空地址。
- 添加、删除普通管理员，并给管理员写一句备注。备注最长 64 字节，可以留空。
- 普通管理员默认最多 200 人，可以用 `setAdminLimit` 调整。新上限不能小于当前人数。超级管理员本人不占这个名额。
- 可以删除任何一条白名单。
- 可以升级合约逻辑。升级时不能附带以太币，也不能附带额外调用。

### 普通管理员

- 只能把自己经手的地址加入白名单，并写备注。
- 一个地址已经在白名单里时，不能改记到自己名下。
- 只能删除自己加入的白名单。删不了别人加入的，也删不了管理员。
- 没有修改白名单或管理员身份的函数。要改，只能先删除再重新添加。
- 被取消管理员身份后，他以前加入的用户仍留在白名单里，添加人不变。

### 查询

- `roleOf` 返回身份：0 普通地址，1 普通管理员，2 超级管理员。
- `isWhitelisted` 只回答在或不在。超级管理员、普通管理员、白名单用户都返回在。
- 全部白名单可以分页读取，一页最多 50 条。
- 管理员可以分页读取自己加入的那一份。
- 名单和备注是公开的，查询不需要权限。

## 本地测试

依赖 Foundry。OpenZeppelin 和 forge-std 已经放在 `lib/`。

```bash
forge test
```

## 部署

把 `.env.example` 复制成 `.env`，填入 Sepolia 的 RPC 和部署私钥。私钥不要提交。

```bash
forge script script/Deploy.s.sol --rpc-url sepolia --broadcast
```

已经部署的代理用 `script/Upgrade.s.sol` 升级，代理地址保持不变。
